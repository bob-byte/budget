# Budget

A Flutter budget tracking app with Firebase authentication and Firestore data storage.

## Tech Stack

- Flutter (Dart)
- Firebase Authentication
- Cloud Firestore
- Riverpod + Flutter Hooks

## Getting Started

### 1) Install dependencies

```bash
flutter pub get
```

### 2) Configure Firebase

Set up Firebase for your target platforms and ensure your Firebase config files are added to the project.

Typical setup includes:
- creating a Firebase project
- enabling Authentication providers (for example, Email/Password and Google Sign-In)
- enabling Cloud Firestore
- adding platform-specific Firebase config files

### 3) Run the app

```bash
flutter run
```
